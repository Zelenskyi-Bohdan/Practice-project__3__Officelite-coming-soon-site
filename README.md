# Officelite Coming Soon Site

A responsive coming soon website for Officelite, built from a Frontend Mentor design challenge.

The project includes a landing page with pricing plans and a countdown timer, as well as a sign-up page with form validation.

# Features

- Responsive layout for mobile, tablet, and desktop
- Pricing plans section
- Countdown timer
- Sign-up form
- Client-side form validation
- Custom error states
- Responsive SVG illustrations
- Hover and focus states
- Reusable JavaScript timer module

# Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
- CSS Flexbox
- CSS Custom Properties
- SVG
